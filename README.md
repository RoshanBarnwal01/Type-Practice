# ⌨️ Type&Practice
**Type&Practice** is a simple typing practice website that helps users practice typing and check their typing performance.

## ✨ Features

- ⌨️ Typing practice with different passages
- 📊 WPM (Words Per Minute) calculation
- 🎯 Typing accuracy
- ❌ Error tracking
- 🟢 Visual feedback for correctly typed characters
- 🔴 Visual feedback for incorrectly typed characters
- 🔄 Restart typing test
- 💾 Typing history saved in browser Local Storage

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How to Run

1. Clone this repository.
2. Open the project in VS Code.
3. Open `index.html` using Live Server or directly in a browser.
